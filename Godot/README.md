# Godot game plans

Seven phased specifications for original Godot 4 games. These are planning prompts, not implemented Godot projects. Start with a plan's handoff instructions and follow its phase gates.

- [Dustline Rover](dustline-rover-godot-game-plan.md) — Moon Patrol-inspired lunar rover shooter.
- [Maze Munchers](maze-munchers-godot-game-plan.md) — Classic maze-chase game.
- [Prism Hopper](prism-hopper-godot-game-plan.md) — Q*bert-inspired isometric platform game.
- [Rift Current](rift-current-godot-game-plan.md) — River Raid-inspired scrolling flight shooter.
- [Shadow Intercept](shadow-intercept-godot-game-plan.md) — Top-down vehicular combat score attack.
- [Shattered Realms](shattered-realms-godot-game-plan.md) — Turn-based territory strategy game.
- [Starfall Chronicles](starfall-chronicles-godot-game-plan.md) — Fantasy RPG with overworld, dungeons, and space combat.
