# AI Testing Prompts

A collection of prompts used to test AI systems. Each Markdown file in this
repository contains a prompt that can be reused or adapted for a test.

## Adding a prompt

- Add one prompt per Markdown file at the repository root.
- Use a short, descriptive, kebab-case filename, such as `code-review.md`.
- Include the complete prompt and any context or constraints needed to run it.
- Avoid including credentials, personal data, or other sensitive information.
