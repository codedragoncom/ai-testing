# Physics and graphics prompts

These prompts range from numerical simulations to real-time 3D rendering. Check each prompt's runtime requirements: some use raw WebGL/WebGPU, while others rely on Three.js.

- [2D Fluid Dynamics](2d-fluid-dynamics-simulator.md) — Interactive 2D fluid solver, intended for a standalone `index.html`.
- [Jelly Dice](jelly-dice-optimized.md) — Deformable soft-body dice using WebGPU and WGSL.
- [Krakatoa: The Eruption](krakatoa-the-eruption.md) — Volcanic scene and GPU simulation using raw WebGL2.
- [Lava: A Living Light](lava-lamp.md) — Raymarched lava lamp using raw WebGL2.
- [Nature: The Living Aquascape](nature-the-living-aquascape.md) — Procedural aquarium built with Three.js.

The 2D fluid prompt credits a Luke's Dev Lab GitHub issue; the Jelly Dice prompt records an X post as its source. See each file for details.
